# Echo — 100% Working Social App

Pure client-side social media app matching the provided UI mockups.

**Open this link (no Expo, no terminal, no server):**  
https://chopdekaradhrit2013-droid.github.io/echo-prototype/

## Screens
- Home Feed (stories + vertical posts with like/comment/share/save)
- Discover (search, categories, masonry, trending creators)
- Create Post (media + caption, location, audience, schedule)
- Chats + Individual Chat (send messages, voice mock, online status)
- Activity / Notifications
- Profile (stats, grid, edit)
- Story Viewer (progress, reactions)
- Reels Player (play, side actions, progress)
- Settings (privacy, security, swipe, appearance...)

## How it works
- Fully interactive navigation
- Likes toggle + toast feedback
- Chat: type and send, auto-reply
- Stories & Reels open as full-screen overlays
- Create Post works (demo toast + return to home)
- Bottom nav with glowing + button
- Dark OLED theme + electric blue / purple accents matching the logo

Built for browser / iPad. Just open the link.
